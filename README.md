## Entry

> It is a post office where every letter ever written arrives in the blink of an eye, and the whole library of the world lies open upon your desk.

One sentence (144 characters) explaining the modern internet to a traveler from 1800, built only from things they already know: a post office, letters, a library, a desk.

## Run

```sh
python3 main.py
```

Prints the sentence and writes it to `/output/entry.txt`.
